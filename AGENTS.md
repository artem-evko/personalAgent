# Правила экономии контекста и работы с памятью

1. **Контроль контекста**: Не читай более 2-3 файлов подряд в основном потоке. Читай файлы диапазонами по 150-250 строк.
2. **Делегируй разведку субагентам**: Для поиска по проекту используй субагента `explore` (инструмент `subagent`).
3. **Смена диалога без потери нити**: Каждые 8-10 шагов (или по команде `/handoff`) записывай слепок состояния напрямую в `.opencode/memory/active_handoff.md` (статус, неочевидные баги, следующие шаги) и `.opencode/memory/project_architecture.md` (архитектура и ключевые контракты), и предлагай пользователю перейти в новый чистый чат (`/new`).
4. **Чтение памяти**: В начале сессии всегда сверяйся с блоком `Слепок состояния проекта (Handoff)` и сразу переходи к разделу `Следующие шаги`, не читая заново уже изученные файлы.
